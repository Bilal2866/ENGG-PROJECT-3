⚡ What We Learned About PWM

PWM = Pulse Width Modulation

Used to control speed (motors) or brightness (LED)

Works by changing duty cycle in a time period

75% duty cycle → more power than 50%

90% duty cycle → almost full power

We will measure PWM using an oscilloscope

PWM will be used with L293D motor driver next week

💡 LED PWM Code (blinko code- TD 2.c)

We used WiringPi and softPWM to control LED brightness with keyboard input.

Commands:

a → 25% brightness

s → 50%

d → 75%

w → 90%

q → OFF

x → Exit program

This was good practice before controlling real motors.
