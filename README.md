⚡ What We Learned About PWM

PWM controls motor speed or LED brightness

It works by changing the duty cycle in a fixed time period

Higher duty cycle = more power output

Required duty cycles: 75% and 90%

We will check PWM using an oscilloscope

PWM will be used with L293D motor driver soon

💡 LED PWM Code (blinko code- TD 2.c)

The program uses WiringPi and softPWM to change LED brightness with keyboard input.

Commands:

a = 25% brightness

s = 50%

d = 75%

w = 90%

q = LED OFF

x = EXIT program

This helped us understand PWM before using it on a motor.
